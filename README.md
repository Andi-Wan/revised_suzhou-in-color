# Suzhou in Color — Preview

Static, no-build preview generated from the five uploaded photograph ZIP files.

Open `index.html` directly in a browser. No backend is required.

## What is real in this preview
- Uploaded source photographs (10 used per place)
- Lightweight dominant-color extraction from those images
- Prototype histogram-based palette similarity

## What is placeholder/demo metadata
- Category assignment
- Photo titles
- Photographer/date/coordinate metadata
- Place descriptions

Structured JSON mirrors the intended scalable architecture in `/data`.
